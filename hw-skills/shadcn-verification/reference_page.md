# 页面设计规范校验方案

## 整体前提

- **校验对象**：完整页面（含预置组件与自定义组件）。
- **校验载体**：无头浏览器（Playwright / Puppeteer）渲染页面。
- **核心逻辑**：页面按“布局 + 页面元素（预置/自定义）”分层计分；样式与规范库对照。

---

## 规范与数据来源（本仓库路径）

| 校验类别 | 规范文件 | 用途 |
| :--- | :--- | :--- |
| 阴影 | `css_styles_specification/shade.json` | 阴影颜色、模糊、偏移、扩展等 |
| 描边 | `css_styles_specification/outline.json` | 描边粗细、颜色等 |
| 颜色 | `css_styles_specification/color.json` | 颜色语义与允许色值 |
| 圆角 | `css_styles_specification/rounded.json` | 统一圆角与四角规则 |
| 间距 | `css_styles_specification/gap.json` | 页面/模块间距、padding、gap 等 |
| 文本 | `css_styles_specification/font.json` | 字体家族、字号、字重等 |

**强制约束（本页面规范）**

- 样式校验**只**基于以上规范文件进行比对。

---

## 一、总分权重结构（页面级）

| 模块 | 权重 / 计分方式 | 说明 |
| :--- | :--- | :--- |
| 页面布局 | 20% | 栅格按合规率计分；背景色错误按规则倒扣 |
| 页面元素 | 80% | 按页面元素占比拆分到预置组件与自定义组件 |
| 合计 | 100% | 页面总分 |

页面总分公式：

`页面总分 = 页面布局得分 + 页面元素得分`

---

## 二、页面布局模块（20%）

### 2.1 栅格（合规率计分）

**校验项**

- 页面左右间距（左/右）
- 元素横向间距
- 楼层纵向间距

**得分公式**

`栅格得分 = (符合规范数 / 总间距检查项数) × 20%`

### 2.2 背景色彩（倒扣）

**规则**

- 页面背景色不符合 `color.json` 规范时，每处错误倒扣 1 分。
- 倒扣后本模块最低为 0 分（不出现负分）。

**布局模块最终得分**

`页面布局得分 = max(0, 栅格得分 - 背景色扣分)`

---

## 三、页面元素模块（80%）

页面元素模块按元素占比拆分为“预置组件”和“自定义组件”两部分。

### 3.1 元素占比权重

- `预置组件权重 = (预置组件元素个数 / 页面元素总数) × 80%`
- `自定义组件权重 = (自定义组件元素个数 / 页面元素总数) × 80%`

### 3.2 预置组件校验

**规则**

- 调用生成：该元素记为 100% 合规。
- 无调用：该元素记为 0% 合规。

**得分公式**

`预置组件得分 = 预置组件权重 × 预置组件合规率`

---

## 四、自定义组件校验流程（用于页面内自定义元素）

自定义组件采用“布局倒扣 + 资源30% + 样式70%”的组合计分。

### 4.1 布局（倒扣分）

**校验项**

- 换行：单字换行、标点换行等问题
- 对齐：左对齐/右对齐/居中/两端对齐

**扣分规则**

- 每发现 1 处独立布局问题，倒扣 1 分。
- 同一问题点只扣 1 次，不重复累计。

### 4.2 资源调用（30%）

**校验项**

- icon：是否调用规范 icon 资源库
- 图片：是否符合规范风格定义
- 插画：是否调用规范插画资源库

**得分公式**

`资源得分 = (合规资源数 / 资源总数) × 30%`

### 4.3 样式（70%）

**比对原则**

- 仅比对页面渲染后关键节点的计算样式（`getComputedStyle()`）。
- 仅依据规范文件允许值/语义判断合规。

#### 样式子项

- 阴影：模糊、Y 轴偏移、X 轴偏移、扩展（按 `shade.json`）
- 描边：粗细（及规范定义字段，按 `outline.json`）
- 颜色：颜色语义与色值（按 `color.json`）
- 圆角：统一圆角与四角（按 `rounded.json`）
- 间距：padding（上/下/左/右）、横向 gap、纵向 gap（按 `gap.json`）
- 文本：字体、字号、字重（按 `font.json`）

**得分公式**

`样式得分 = (合规样式属性数 / 样式属性总数) × 70%`

### 4.4 自定义组件得分公式

`自定义组件原始得分 = 资源得分 + 样式得分`

`自定义组件最终得分 = max(0, 自定义组件原始得分 - 布局扣分)`

`页面侧折算得分 = 自定义组件权重 × 自定义组件最终得分`

---

## 五、页面总分合成

`页面总分 = 页面布局得分 + 预置组件得分 + 页面侧折算后的自定义组件得分`

为避免歧义，报告中必须同时给出：

- 页面元素总数、预置组件元素数、自定义组件元素数
- 预置/自定义的权重值
- 布局扣分明细（问题点与扣分条目）
- 资源/样式分子分母与得分计算过程

---

## 六、执行流程（落地步骤）

1. 渲染目标页面，生成可稳定复现的截图与 DOM 快照。
2. 统计页面元素并分类为预置组件/自定义组件，计算各自权重。
3. 执行页面布局检查（栅格 + 背景色），得到布局模块分数。
4. 预置组件按“调用生成/无调用”计算合规率与得分。
5. 自定义组件执行布局、资源、样式校验，生成明细与分值。
6. 汇总页面总分，并输出可复核的分子/分母与扣分来源。

---

## 七、输出要求

建议输出以下两类结果（页面级）：

- `verification_result.md`：页面总分、分模块得分、扣分明细、关键不符合项。
- `verification_key_styles.xlsx`：按页面模块/元素分组的统计结果与问题明细。

输出约束：

- 必须能从结果回溯到“规范来源（对应 json）+ 实际样式值”。
- 不输出与本规范无关的 DSL 对照结论。
