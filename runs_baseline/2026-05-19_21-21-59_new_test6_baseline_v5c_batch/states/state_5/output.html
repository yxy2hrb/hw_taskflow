华为云Stack部署指南

华为云Stack是面向政企客户的全栈专属云解决方案，支持混合云统一管理、本地化部署与自主可控。本指南适用于初次部署华为云Stack的系统工程师与交付团队。

部署前准备

请确保满足以下基础环境要求：

  1. 服务器硬件配置：≥64核CPU、≥256GB内存、≥4TB NVMe存储（推荐双机高可用架构）
  2. 网络规划：需划分Management、Storage、Service三个独立VLAN，各网段互不通信
  3. 软件依赖：CentOS 7.9 或 EulerOS 22.03 SP1，内核版本 ≥ 4.19.90
  4. License文件：已从华为云官网下载并校验SHA256签名

安装步骤

按照以下顺序执行安装操作：

  1. 上传安装包至主控节点：huaweicloudstack-installer-v6.5.0.tar.gz
  2. 解压并进入目录：tar -xzf huaweicloudstack-installer-v6.5.0.tar.gz && cd installer
  3. 运行预检脚本：./precheck.sh --mode=full
  4. 生成部署配置：./config-generator.sh -t allinone -n cloud1
  5. 启动静默安装：nohup ./install.sh > install.log 2>&1 &
# 查看安装进度
tail -f install.log | grep -E "(PROGRESS|SUCCESS|FAILED)"
# 预期输出示例：
[PROGRESS]  Step 3/12: Initializing database...
[SUCCESS]  Step 5/12: Deploying control plane services.

安装完成后，可通过浏览器访问 https://cloud1.hwc.local:31100 登录控制台，默认账号：admin，密码见 /opt/huaweicloudstack/installer/output/passwords.txt。

⚠️ 注意：首次登录后请立即修改默认密码，并在「安全中心」中启用双因素认证（2FA）。
