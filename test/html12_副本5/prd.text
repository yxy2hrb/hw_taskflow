## 1. 业务流程与架构图 (修正)

此模块在【个人中心】包含两个独立的业务分支，互不干扰。

* **流程 A (通讯录/成员)**：个人中心 -> 点击[成员管理]图标 -> 进入成员列表页。
* **流程 B (权限配置)**：个人中心 -> 点击[权限管理]列表项 -> 进入权限详情页 -> 编辑/保存。

## 4. 核心页面三：权限配置详情 (核心业务)
**前置来源**：直接由 [个人中心]-[权限管理] 进入。

### 4.1 页面状态逻辑
此页面包含**查看态**和**编辑态**。
#### A. 查看态 (Initial State)
* **标题**：`查看权限`
* **展示字段**：
* **设置权限有效期限到日期**：显示当前截止日期（如 `2023-05-12`）。
* **已有角色**：
* 计数：`已选 X 种`。
* 列表：只读展示当前拥有的角色名称（如 `商务人员`、`销售人员`）。
* **底部操作**：
* 按钮文案：`权限管理`
* 交互：点击切换至 **[B. 编辑态]**。
#### B. 编辑态 (Edit State)
* **标题**：`权限管理`
* **交互控件**：
1. **日期修改**：点击有效期行 -> 底部弹出 `Date Picker` -> 选择新日期。
2. **角色修改**：
* 显示**全量角色列表**（带 Checkbox）。
* 支持取消勾选、新增勾选。




* **底部操作**：
* 按钮文案：`确定`
* 状态：
* Default：置灰（无变更）。
* Active：高亮蓝色（有变更）。


* 交互：点击提交接口 -> 成功后 Toast `保存成功` -> 自动切回 [查看态] 并刷新数据。
